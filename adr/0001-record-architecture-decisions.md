# ADR-0001: Record Architecture Decisions in oengo-web

- **Status:** Accepted
- **Deciders:** Enterprise Architecture Board, Domain Lead
- **Date:** 2026-11-15

## Context and Problem Statement
We need an immutable, transparent method to record architectural and design decisions for oengo-web.

## Decision Outcome
We will use Architectural Decision Records (ADRs) following the MADR format within the \/adr/\ directory of this repository.
